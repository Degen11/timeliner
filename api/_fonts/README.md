Fonts used by `api/og.js` to render per-share preview images. Satori (inside
`@vercel/og`) can't read woff2, so these are the `.woff` latin + latin-ext
subsets copied from the Fontsource packages:

- Newsreader 600 (`@fontsource/newsreader`)
- Plus Jakarta Sans 700 (`@fontsource/plus-jakarta-sans`)
- Inter 500 (`@fontsource/inter`)

All three are licensed under the SIL Open Font License 1.1.
