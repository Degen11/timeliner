# groupByYear doc claims it is shared by selectors, but selectors use a separate getEventsByYear with different (sort-preserving) semantics

Confirmed by detect-signage: dateUtils.js:197 says groupByYear is shared by selectors, but grep shows it is imported only by exportHelpers.js and exportText.js. selectors.js:91 has its own getEventsByYear, which keeps the caller's order and supports DATE_DESC, while groupByYear re-sorts ascending (dateUtils.js:200). A provable contradiction between the doc and the code.

Evidence:
- src/utils/dateUtils.js:197
- src/utils/dateUtils.js:200
- src/store/selectors.js:91
- src/store/selectors.js:92
